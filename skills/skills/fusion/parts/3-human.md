## Checkpoint 3 (optional): Followup Human Question

This checkpoint should start with a `HUMAN_QUESTION` header. Use this checkpoint to ask the human for clarification when the repo cannot answer the ambiguity.

You can ask multiple questions to the user. Questions should be pointed and precise. Prefer multiple choice questions if there truely are multiple paths to take. State how each choice changes the plan.

Do not pick multiple-choice questions if there is only one plausible path.

Completion criterion: the answers unblock a concrete planning decision.
