## Checkpoint 5: Generate Implementation Plan

Based on the back and forth with the human, generate a detailed implementation plan. This is the plan that the implementation agent will follow.

Before you generate the plan, there are a few guidelines you need to keep in mind:

Whenever we are implementing a new feature or adding a substantial new function or code, read the the following skills:

- [principle-type-system-discipline](docs/skills/code/principle-type-system-discipline.md)
- [principle-subtract-before-you-add](docs/skills/code/principle-subtract-before-you-add.md)
- [principle-boundary-discipline](docs/skills/code/principle-boundary-discipline.md)
- [principle-foundational-thinking](docs/skills/code/principle-foundational-thinking.md)
- [principle-minimize-reader-load](docs/skills/code/principle-minimize-reader-load.md)
- [principle-laziness-protocol](docs/skills/code/principle-laziness-protocol.md)
- [principle-typescript-best-practices](docs/skills/code/principle-typescript-best-practices.md)

In your plan, give the implementation agent an overview of the data model, boundaries, and interfaces that need to be implemented as well.
