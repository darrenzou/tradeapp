rea (MCP tools named `mcp__rea__*`) inspects apps, websites and program files without their source. JavaScript, website, .NET and package tools work right away. Before decompiling a compiled program (native binary) with rea, run `bash .claude/tools/install-ghidra.sh` once in the session (about 40 seconds), then pass `provider_id: "ghidra"` to `open_binary`. Hopper and IDA are not available in the cloud.
