Firecrawl (MCP tools named `mcp__firecrawl__*`) reads websites for you. Use `firecrawl_scrape` when WebFetch fails on a page (JavaScript-heavy sites, bot blocks, PDFs), `firecrawl_search` for a web search that returns each result's page content, `firecrawl_map` to list a site's pages, and `firecrawl_crawl` only when you need many pages. Each call spends credits from Darren's Firecrawl plan, so try the built-in WebSearch and WebFetch first for simple lookups.
